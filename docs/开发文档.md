## 一、项目概述

### 1.1 项目背景

基于微信公众号平台，构建一套智能客服系统。用户通过微信公众号发送文本、图片、语音消息，系统接入大语言模型（LLM）进行智能回复，支持文本、图片、语音三种回复形式。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| 微信接入 | 对接微信公众号开发接口，完成服务器验证与消息收发 |
| 消息收发 | 支持接收/发送文本、图片、语音消息 |
| LLM 智能回复 | 接入大模型 API，实现文本生成、图片生成/理解、语音合成 |
| 可扩展架构 | 模块化设计，支持后续扩展更多消息类型和模型能力 |

### 1.3 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 语言 | Java 17 | LTS 版本，稳定可靠 |
| 构建工具 | Maven 3.9+ | 标准化依赖管理 |
| Web 框架 | Spring Boot 3.2 | 快速构建 RESTful 服务 |
| 微信 SDK | WxJava (`weixin-java-mp`) | 成熟的微信公众号 Java SDK |
| LLM 接入 | OpenAI兼容接口 / 通义千问 | 支持 text/image/voice 多模态 |
| HTTP 客户端 | OkHttp | 调用 LLM API |
| JSON 处理 | Jackson | 消息序列化/反序列化 |
| 日志 | Logback | Spring Boot 内置 |
| 部署 | Docker + Nginx | 容器化部署，Nginx 反向代理 |

## 三、详细设计

### 3.1 微信公众号接入

#### 3.1.1 公众号配置

| 配置项 | 说明 |
|--------|------|
| AppID | 公众号唯一标识 |
| AppSecret | 公众号密钥 |
| Token | 服务器验证 Token（自定义） |
| EncodingAESKey | 消息加解密密钥 |
| 服务器URL | `https://域名/wx/msg` |

#### 3.1.2 服务器验证

微信服务器会向配置的 URL 发送 GET 请求，携带 `signature`、`timestamp`、`nonce`、`echostr` 参数。服务端需验证签名后原样返回 `echostr`。

> 使用 WxJava SDK 自动完成签名验证，无需手动实现。

#### 3.1.3 消息接收

微信将用户消息以 XML 格式 POST 到服务器 URL，支持的消息类型：

| 消息类型 | XML MsgType | 关键字段 |
|----------|-------------|----------|
| 文本 | `text` | `Content` - 文本内容 |
| 图片 | `image` | `PicUrl` - 图片URL |
| 语音 | `voice` | `MediaId` / `Recognition`（需开启语音识别） |
| 事件 | `event` | `Event` - 事件类型 (subscribe/CLICK等) |

#### 3.1.4 消息发送

通过微信接口主动发送消息或被动回复消息：

- **被动回复**: 收到用户消息后，在 5 秒内返回 XML 格式的回复消息
- **客服消息**: 通过客服接口主动推送（用于异步场景，如 LLM 响应较慢时）

**被动回复消息格式**:

```xml
<!-- 文本 -->
<xml>
  <ToUserName><![CDATA[用户openid]]></ToUserName>
  <FromUserName><![CDATA[公众号原始ID]]></FromUserName>
  <CreateTime>时间戳</CreateTime>
  <MsgType><![CDATA[text]]></MsgType>
  <Content><![CDATA[回复内容]]></Content>
</xml>

<!-- 图片 -->
<xml>
  <ToUserName><![CDATA[用户openid]]></ToUserName>
  <FromUserName><![CDATA[公众号原始ID]]></FromUserName>
  <CreateTime>时间戳</CreateTime>
  <MsgType><![CDATA[image]]></MsgType>
  <Image>
    <MediaId><![CDATA[素材ID]]></MediaId>
  </Image>
</xml>

<!-- 语音 -->
<xml>
  <ToUserName><![CDATA[用户openid]]></ToUserName>
  <FromUserName><![CDATA[公众号原始ID]]></FromUserName>
  <CreateTime>时间戳</CreateTime>
  <MsgType><![CDATA[voice]]></MsgType>
  <Voice>
    <MediaId><![CDATA[素材ID]]></MediaId>
  </Voice>
</xml>
```

### 3.2 LLM 大模型接入

#### 3.2.1 模型选型

| 能力 | 推荐模型 | 备选 | 说明 |
|------|----------|------|------|
| 文本对话 | 通义千问 `qwen-plus` | GPT-4o / DeepSeek | 支持多轮对话 |
| 图片理解 | 通义千问 `qwen-vl-plus` | GPT-4o | 理解用户发送的图片 |
| 图片生成 | 通义万相 `wanx-v1` | DALL-E 3 | 根据文本生成图片 |
| 语音合成 | CosyVoice | Azure TTS | 文本转语音 |

> 优先使用阿里云通义系列模型（国内访问稳定、API 兼容性好），通过 DashScope API 调用。

#### 3.2.2 API Key 管理

```yaml
# application.yml
llm:
  provider: dashscope  # 大模型服务商
  dashscope:
    api-key: ${DASHSCOPE_API_KEY}  # 从环境变量读取，不硬编码
    base-url: https://dashscope.aliyuncs.com/api/v1
    text-model: qwen-plus
    vision-model: qwen-vl-plus
    image-model: wanx-v1
    tts-model: cosyvoice-v1
```

#### 3.2.3 LLM 调用接口设计

```
LLMService 接口:
├── String chatText(String userMessage, List<Message> history)
│   └── 文本对话，返回回复文本
├── String chatWithImage(String userMessage, String imageUrl)
│   └── 图片理解，返回文本描述
├── String generateImage(String prompt)
│   └── 图片生成，返回图片URL
└── byte[] textToSpeech(String text)
    └── 语音合成，返回音频二进制数据
```

### 3.3 消息处理器设计

采用策略模式，按消息类型分发到不同 Handler：

```
MessageHandler (接口)
├── boolean supports(String msgType)
└── WxMpXmlOutMessage handle(WxMpXmlMessage inMessage)

TextMessageHandler     # 文本消息 → LLM文本对话
ImageMessageHandler    # 图片消息 → LLM图片理解
VoiceMessageHandler    # 语音消息 → 语音转文字 → LLM对话 → 语音合成
EventMessageHandler    # 事件消息 (关注/菜单点击等)
```

### 3.4 异步处理机制

由于 LLM 响应可能超过微信 5 秒限制，采用异步策略：

```
用户消息到达
    │
    ├─ 立即回复 "正在思考中..." (被动回复，满足5秒限制)
    │
    └─ 异步线程处理:
         ├─ 调用 LLM 获取回复
         ├─ 如果回复是图片 → 上传微信素材 → 获取 MediaId
         ├─ 如果回复是语音 → 上传微信素材 → 获取 MediaId
         └─ 通过客服消息接口主动推送最终回复
```

### 3.5 微信素材管理

发送图片和语音消息需要先上传素材获取 `MediaId`：

```
上传流程:
1. LLM 生成图片/语音 → 获取文件
2. 调用微信素材上传接口 (POST /media/upload)
3. 获取 media_id
4. 使用 media_id 构建回复消息
```

## 六、接口清单

### 6.1 微信消息接口

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 服务器验证 | GET | `/wx/msg` | 微信服务器签名验证 |

### 6.2 LLM 服务接口 (内部调用)

| 方法 | 入参 | 出参 | 说明 |
|------|------|------|------|

### 6.3 微信素材接口 (内部调用)

| 方法 | 入参 | 出参 | 说明 |
|------|------|------|------|
| `uploadImage` | 图片文件 | mediaId | 上传图片素材 |
| `uploadVoice` | 语音文件 | mediaId | 上传语音素材 |
| `sendCustomMessage` | openid + 消息体 | void | 发送客服消息 |

## 九、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| LLM 响应超时 (>5s) | 微信重试推送 | 异步处理 + 客服消息推送 |
| 微信素材上传失败 | 图片/语音无法回复 | 重试机制 + 降级为文本回复 |
| API Key 泄露 | 安全风险 | 环境变量管理，不提交代码 |
| 公众号接口权限不足 | 部分功能不可用 | 确认公众号已认证，获取所需接口权限 |
| 语音识别未开启 | 无法处理语音消息 | 公众号后台开启"语音识别"功能 |

### B. DashScope API Key 申请流程

1. 注册阿里云账号并实名认证
2. 开通 DashScope 服务: https://dashscope.console.aliyun.com/
3. 进入 API-KEY 管理，创建新的 API Key
4. 将 API Key 配置到环境变量 `DASHSCOPE_API_KEY`

### C. 微信公众号配置流程

1. 注册微信公众号 (订阅号/服务号)
2. 进入"开发 → 基本配置"，获取 AppID 和 AppSecret
3. 配置服务器地址、Token、EncodingAESKey
4. 开启"语音识别"功能 (开发 → 接口权限)
5. 确保服务器已部署并可外网访问
